# Privacy policy: Home Assistant Calendar

Last updated November 4, 2026

What it accesses: events on the one Google Calendar that was connected (titles, times and locations). Home Assistant can also add events to that calendar.

How it's used: only to show upcoming events and send reminders inside the home.

Where it's kept: on the household's own Home Assistant server. Nothing is sold, shared with anyone else, or used for advertising.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access: the account owner can revoke it at any time at myaccount.google.com/permissions.
